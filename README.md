# ☕ Análise de Clientes em Java (CSV)

Programa de console em **Java** que carrega uma base de clientes em CSV e permite **buscar um cliente pelo CPF** ou **listar todos**, de forma interativa. Projeto de estudo de leitura e tratamento de dados com Java puro.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## ▶️ Como rodar
1. Ajuste o caminho do CSV na variável `arquivoCSV` em `src/AnaliseDadosJava.java`.
2. Compile e rode:

```bash
javac src/AnaliseDadosJava.java -d out
java -cp out AnaliseDadosJava
```
